# Skillway

Prototipo web de Skillway: oportunidades de voluntariado, destinos, comunidad y guardados.

## Ver el proyecto

Sitio estático en HTML, CSS y JavaScript, sin instalación ni compilación.
Para probarlo localmente, ejecutar `python3 -m http.server 8000` desde esta carpeta y abrir `http://localhost:8000`.

## Publicar en GitHub Pages

En el repositorio, ir a Settings → Pages y seleccionar Deploy from a branch, rama `main`, carpeta `/ (root)`.

## Datos de demostración

Los guardados y otras interacciones se almacenan en el navegador. Los mensajes y las postulaciones son demostraciones locales; no se envían a otras personas.
